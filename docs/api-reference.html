GCanvas

The main drawing surface. All rendering operations are performed through a GCanvas instance.

Function Signature Description
GCreateCanvas std::unique_ptr<GCanvas> GCreateCanvas(const GBitmap&) Factory function that creates a canvas from a bitmap. Returns nullptr if bitmap is invalid.
save void save() Saves the current canvas state (CTM) onto a stack. Must be balanced with restore().
restore void restore() Restores the canvas state (CTM) from the most recent save(). Error to call without prior save().
concat void concat(const GMatrix&) Modifies the CTM by pre-concatenating with the specified matrix: CTM' = CTM * matrix
clear void clear(const GColor&) Fills the entire canvas with the specified color using kSrc blend mode.
drawRect void drawRect(const GRect&, const GPaint&) Draws a filled rectangle. Pixels are considered inside if center > min_edge && center <= max_edge.
drawConvexPolygon void drawConvexPolygon(const GPoint[], int count, const GPaint&) Draws a filled convex polygon specified by count points. Uses same containment rule as rectangles.
drawPath void drawPath(const GPath&, const GPaint&) Fills a path using the non-zero winding fill rule.
drawMesh void drawMesh(const GPoint verts[], const GColor colors[], const GPoint texs[], int count, const int indices[], const GPaint&) Draws a mesh of triangles. Vertices specified by indices array (triples). Optional per-vertex colors and texture coordinates.
drawQuad void drawQuad(const GPoint verts[4], const GColor colors[4], const GPoint texs[4], int level, const GPaint&) Draws a quad tessellated to the specified level. Level 0 = 2 triangles, level 1 = 8 triangles, etc.
translate void translate(float x, float y) Helper that applies a translation matrix to the CTM.
scale void scale(float x, float y) Helper that applies a scaling matrix to the CTM.
rotate void rotate(float radians) Helper that applies a rotation matrix to the CTM.
fillRect void fillRect(const GRect&, const GColor&) Helper that draws a filled rectangle with a solid color (no shader).

Usage Example

// Create a canvas from a bitmap
GBitmap bitmap;
bitmap.alloc(256, 256);
auto canvas = GCreateCanvas(bitmap);

// Save state and apply transformations
canvas->save();
canvas->translate(128, 128);
canvas->rotate(M_PI / 4);  // 45 degrees

// Draw a red rectangle
GPaint paint;
paint.setColor(GColor::RGB(1, 0, 0));
paint.setBlendMode(GBlendMode::kSrcOver);
canvas->drawRect(GRect::XYWH(-50, -50, 100, 100), paint);

// Restore state
canvas->restore();

GShader

Abstract base class for shaders that generate colors for filling geometry. Shaders are set on GPaint objects.

Function Signature Description
isOpaque bool isOpaque() Returns true if all pixels generated by this shader are fully opaque (alpha = 1.0).
setContext bool setContext(const GMatrix& ctm) Called before shadeRow() with the current transformation matrix. Returns false if shader cannot be used.
shadeRow void shadeRow(int x, int y, int count, GPixel row[]) Fills row array with count pixels for the scanline at [x, y] to [x + count - 1, y].
GCreateBitmapShader std::unique_ptr<GShader> GCreateBitmapShader(const GBitmap&, const GMatrix& localMatrix, GTileMode) Creates a shader that samples from a bitmap with the specified tile mode (kClamp, kRepeat, kMirror).
GCreateLinearGradient std::unique_ptr<GShader> GCreateLinearGradient(GPoint p0, GPoint p1, const GColor[], int count, GTileMode) Creates a linear gradient shader from p0 to p1 with count color stops evenly distributed.
GCreateLinearGradient std::unique_ptr<GShader> GCreateLinearGradient(GPoint p0, GPoint p1, const GColor& c0, const GColor& c1, GTileMode) Helper that creates a two-color linear gradient.

GPaint

Encapsulates drawing attributes: color, blend mode, and optional shader. Used with all GCanvas draw operations.

Function Signature Description
GPaint GPaint() Default constructor. Color = black (opaque), blend mode = kSrcOver, no shader.
GPaint GPaint(const GColor&) Constructor that sets the color.
GPaint GPaint(GShader*) Constructor that sets the shader.
getColor const GColor& getColor() const Returns the current color.
setColor GPaint& setColor(GColor) Sets the color and returns *this for method chaining.
setRGBA GPaint& setRGBA(float r, float g, float b, float a) Sets the color from RGBA components [0..1] and returns *this.
getAlpha float getAlpha() const Returns the alpha component of the color.
setAlpha GPaint& setAlpha(float) Sets the alpha component and returns *this.
getBlendMode GBlendMode getBlendMode() const Returns the current blend mode.
setBlendMode GPaint& setBlendMode(GBlendMode) Sets the blend mode and returns *this.
getShader GShader* getShader() const Returns the current shader (nullptr if none).
setShader GPaint& setShader(GShader*) Sets the shader and returns *this. Pass nullptr to remove shader.

GPath

Represents a geometric path composed of lines and Bezier curves. Used with GCanvas::drawPath().

Function Signature Description
GPath GPath() Constructor that creates an empty path.
reset void reset() Erases all points and verbs, returning the path to empty state.
moveTo void moveTo(GPoint) / void moveTo(float x, float y) Starts a new contour at the specified point.
lineTo void lineTo(GPoint) / void lineTo(float x, float y) Adds a line segment from the previous point to the specified point.
quadTo void quadTo(GPoint, GPoint) / void quadTo(float x1, float y1, float x2, float y2) Adds a quadratic Bezier curve with one control point.
cubicTo void cubicTo(GPoint, GPoint, GPoint) / void cubicTo(float x1, float y1, float x2, float y2, float x3, float y3) Adds a cubic Bezier curve with two control points.
addRect void addRect(const GRect&, Direction) Appends a rectangle contour in the specified direction (kCW_Direction or kCCW_Direction).
addPolygon void addPolygon(const GPoint[], int count) Appends a polygon contour from an array of points.
addCircle void addCircle(GPoint center, float radius, Direction) Appends an approximate circle (8 quadratic curves) in the specified direction.
bounds GRect bounds() const Returns the tight bounding box of all path segments. Returns empty rect if path is empty.
transform void transform(const GMatrix&) Transforms all points in the path by the specified matrix in-place.
offset void offset(float dx, float dy) Helper that translates the path by (dx, dy).
ChopQuadAt static void ChopQuadAt(const GPoint src[3], GPoint dst[5], float t) Subdivides a quadratic Bezier at parameter t. Result in dst[0..2] (0 to t) and dst[2..4] (t to 1).
ChopCubicAt static void ChopCubicAt(const GPoint src[4], GPoint dst[7], float t) Subdivides a cubic Bezier at parameter t. Result in dst[0..3] (0 to t) and dst[3..6] (t to 1).

GMatrix

Represents a 3x3 affine transformation matrix for 2D graphics. Used for transformations and coordinate mapping.

Function Signature Description
GMatrix GMatrix() Constructor that creates an identity matrix.
GMatrix GMatrix(float a, float c, float e, float b, float d, float f) Constructor that creates a matrix from 6 values: [a c e; b d f; 0 0 1]
Translate static GMatrix Translate(float tx, float ty) Returns a translation matrix.
Scale static GMatrix Scale(float sx, float sy) Returns a scaling matrix.
Rotate static GMatrix Rotate(float radians) Returns a rotation matrix (counter-clockwise).
Concat static GMatrix Concat(const GMatrix& a, const GMatrix& b) Returns the product of two matrices: a * b
invert std::optional<GMatrix> invert() const Returns the inverse matrix if it exists, otherwise returns empty optional.
mapPoints void mapPoints(GPoint dst[], const GPoint src[], int count) const Transforms count points from src to dst. src and dst can point to the same memory.
mapPoints void mapPoints(GPoint pts[], int count) const Helper that transforms points in-place.
operator* GMatrix operator*(const GMatrix&) const Matrix multiplication operator. Returns Concat(this, other).
operator* GPoint operator*(GPoint) const Point transformation operator. Applies matrix to a single point.

GColor

Represents an unpremultiplied RGBA color with floating-point components in [0..1] range.

Function Signature Description
RGBA static GColor RGBA(float r, float g, float b, float a) Creates a color from RGBA components [0..1].
RGB static GColor RGB(float r, float g, float b) Creates an opaque color from RGB components [0..1]. Alpha defaults to 1.0.
pinToUnit GColor pinToUnit() const Clamps all components to [0..1] range and returns the result.

Note: GColor is a struct with public members r, g, b, a. It also provides operator overloads for arithmetic operations (+, -, *, etc.).

GRect

Represents a floating-point rectangle defined by left, top, right, bottom edges.

Function Signature Description
LTRB static GRect LTRB(float l, float t, float r, float b) Creates a rectangle from left, top, right, bottom edges.
XYWH static GRect XYWH(float x, float y, float w, float h) Creates a rectangle from position (x, y) and size (w, h).
WH static GRect WH(float w, float h) Creates a rectangle at origin (0, 0) with size (w, h).
x / y float x() const / float y() const Returns the left/top coordinate.
width / height float width() const / float height() const Returns the width/height (right - left or bottom - top).
offset GRect offset(float dx, float dy) const Returns a new rectangle translated by (dx, dy).
isEmpty bool isEmpty() const Returns true if width or height is non-positive.
round GIRect round() const Returns an integer rectangle by rounding all edges to nearest integer.
roundOut GIRect roundOut() const Returns an integer rectangle by expanding outward (floor left/top, ceil right/bottom).

Note: GIRect is the integer version with the same API but int32_t values instead of float.

GBlendMode

Enum class defining Porter-Duff compositing blend modes. Used with GPaint to control how source pixels combine with destination pixels.

Mode Formula Description
kClear 0 Clear destination to transparent black.
kSrc S Replace destination with source.
kDst D Keep destination unchanged (no-op).
kSrcOver S + (1 - Sa) * D Source over destination (normal alpha blending).
kDstOver D + (1 - Da) * S Destination over source.
kSrcIn Da * S Source clipped by destination alpha.
kDstIn Sa * D Destination clipped by source alpha.
kSrcOut (1 - Da) * S Source outside destination alpha.
kDstOut (1 - Sa) * D Destination outside source alpha.
kSrcATop Da * S + (1 - Sa) * D Source atop destination.
kDstATop Sa * D + (1 - Da) * S Destination atop source.
kXor (1 - Sa) * D + (1 - Da) * S XOR mode (non-overlapping areas).

Legend: S = source color (premultiplied), D = destination color (premultiplied), Sa = source alpha, Da = destination alpha. All formulas operate component-wise on premultiplied ARGB values.
