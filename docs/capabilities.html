Introduction

This page provides a comprehensive catalog of all features implemented in the 2D graphics engine. Each feature is linked to its documentation page (for algorithm explanations and C++ code) and its interactive demo (for live, browser-based visualization).

The engine was built incrementally across six programming assignments, starting with basic shape rasterization and progressing to advanced features like Bezier curves, gradient shaders, and Coons patches. This catalog organizes features by category, showing the full scope of the rendering system.
