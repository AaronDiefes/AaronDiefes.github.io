  <name>Task 1: Create CPUVisualizer coordinator with DOM creation and event wiring</name>
  <files>cpu-simulator/src/visualization/cpu-visualizer.js</files>
  <action>
Create `cpu-simulator/src/visualization/cpu-visualizer.js` wrapped in IIFE with `window.CPUVisualizer` export.

**CPUVisualizer class:**

**Constructor(container):**
- Store `this.container = container`
- Call `this._createDOM()` to build the visualization layout
- Initialize child components:
  - `this.pipelineView = new PipelineView(this.container.querySelector('[data-pipeline-view]'))`
  - `this.registerView = new RegisterView(this.container.querySelector('[data-register-view]'))`
  - `this.executionView = new ExecutionView(this.container.querySelector('[data-execution-view]'))`
- Bind and register event listener:
  - `this._handleFrameChange = this._handleFrameChange.bind(this)`
  - `window.addEventListener('cpu:framechange', this._handleFrameChange)`

**_createDOM():**
Build the visualization layout inside this.container. Set container class to 'cpu-visualizer'. Create innerHTML:

```html
<section class="pipeline-section">
  <h2>Pipeline Stages</h2>
  <div class="pipeline-stages" data-pipeline-view></div>
</section>
<aside class="data-section">
  <section class="registers-section">
    <h2>Registers</h2>
    <div class="register-grid" data-register-view></div>
  </section>
  <section class="execution-section">
    <h2>Execution State</h2>
    <div data-execution-view aria-live="polite">
      <p>Cycle: <span data-cycle-count>0</span></p>
      <p>Instructions: <span data-instruction-count>0</span></p>
    </div>
  </section>
</aside>
```

**_handleFrameChange(event):**
- Extract state from `event.detail.state`
- If state exists, delegate to child components:
  - `this.pipelineView.render(state)`
  - `this.registerView.render(state)`
  - `this.executionView.render(state)`

**render(state):**
- Public method for manual rendering (without events)
- Delegates to all three child views: pipelineView.render(state), registerView.render(state), executionView.render(state)

**destroy():**
- Remove event listener: `window.removeEventListener('cpu:framechange', this._handleFrameChange)`
- Clear container innerHTML
- Null out child view references
  </action>
