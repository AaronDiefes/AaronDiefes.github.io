<task type="auto">
  <name>Task 1: Create TimingController for speed-adjusted delta-time playback</name>
  <files>cpu-simulator/src/animation/timing-controller.js</files>
  <action>
Create directory `cpu-simulator/src/animation/` and the `timing-controller.js` file.

Implement a `TimingController` class that manages playback speed and calculates frame intervals.

**Properties:**
- `speed`: Current speed multiplier (default: 1.0)
- `baseFPS`: Base frames per second (default: 2 -- CPU simulation frames are educational, not smooth animation; 2 FPS = one pipeline step every 500ms at 1x speed)
- `lastFrameTime`: Timestamp of last frame advance (for delta-time)
- `minSpeed`: 0.25 (quarter speed)
- `maxSpeed`: 4.0 (4x speed)
- `speedPresets`: `{ slow: 0.5, normal: 1.0, fast: 2.0, fastest: 4.0 }` -- named speed presets for UI

**Methods:**
- `setSpeed(multiplier)`: Clamps to [minSpeed, maxSpeed], updates `speed`. Returns actual speed set.
- `getFrameInterval()`: Returns `(1000 / this.baseFPS) / this.speed` in milliseconds. At 1x with baseFPS=2: 500ms between frames.
- `shouldAdvanceFrame(currentTime)`: Compares `currentTime - this.lastFrameTime` against `getFrameInterval()`. Returns `true` if enough time has passed. Updates `lastFrameTime` with leftover accumulation to prevent drift: `this.lastFrameTime = currentTime - (deltaTime % frameInterval)`.
- `reset()`: Sets `lastFrameTime` to `performance.now()`. Call when starting/resuming playback.
- `getSpeedLabel()`: Returns human-readable string like "1x", "0.5x", "2x".

**Key design notes:**
- baseFPS of 2 means at normal speed, one animation frame every 500ms. This gives users time to observe each pipeline state change. At 4x, it's 8 frames/second (125ms per frame) for fast demonstration.
- Delta-time accumulation prevents frame drift on variable refresh rate monitors (60Hz, 120Hz, 144Hz).
- Do NOT use setInterval or setTimeout for timing. Only provide calculation methods -- AnimationEngine handles the rAF loop.

Export via `window.TimingController = TimingController;`. Wrap in IIFE.
  </action>
  <verify>
In browser console:
1. `const tc = new TimingController()`
2. `tc.speed === 1.0`
3. `tc.getFrameInterval() === 500` (1000/2/1.0)
4. `tc.setSpeed(2.0); tc.getFrameInterval() === 250`
5. `tc.setSpeed(0.1); tc.speed === 0.25` (clamped to min)
6. `tc.setSpeed(10); tc.speed === 4.0` (clamped to max)
7. `tc.getSpeedLabel() === '4x'`
  </verify>
  <done>TimingController manages playback speed (0.25x-4x), calculates frame intervals with delta-time accumulation for framerate-independent playback, provides named speed presets, and prevents frame drift on variable refresh rate displays.</done>

<task type="auto">
  <name>Task 2: Create AnimationEngine with frame navigation, playback, and event dispatch</name>
  <files>cpu-simulator/src/animation/animation-engine.js</files>
  <action>
Create `animation-engine.js` in `cpu-simulator/src/animation/`.

Implement an `AnimationEngine` class that manages frame-based animation playback.

**Properties:**
- `frames`: Array of frame objects (loaded via `loadFrames()`)
- `currentFrame`: Integer index into frames array (0-based)
- `isPlaying`: Boolean playback state
- `timing`: Instance of `TimingController`
- `rafId`: requestAnimationFrame ID for cancellation
- `onFrameChange`: Callback function (optional, alternative to events)

**Constructor:**
- Creates new `TimingController` instance
- Initializes with empty frames array, currentFrame=0, isPlaying=false

**Navigation methods:**
- `loadFrames(framesArray)`: Replaces frames, pauses playback, resets to frame 0, dispatches frame change. Validates that framesArray is a non-empty array.
- `stepForward()`: If `currentFrame < frames.length - 1`, increment and dispatch. Returns boolean (true if moved).
- `stepBackward()`: If `currentFrame > 0`, decrement and dispatch. Returns boolean (true if moved).
- `jumpToFrame(index)`: If index in range `[0, frames.length - 1]`, set currentFrame and dispatch. Returns boolean.
- `getCurrentState()`: Returns `this.frames[this.currentFrame]` (the current frame object).
- `getProgress()`: Returns `{ current: this.currentFrame, total: this.frames.length, percent: (this.currentFrame / Math.max(1, this.frames.length - 1)) * 100 }`.

**Playback methods:**
- `play()`: If not already playing and frames exist, set isPlaying=true, call `this.timing.reset()`, start rAF loop via `this._animate()`.
- `pause()`: Set isPlaying=false, cancel rAF if active.
- `togglePlayPause()`: Convenience method, calls play() or pause().
- `reset()`: Pause, set currentFrame=0, dispatch frame change.
- `isAtStart()`: Returns `this.currentFrame === 0`.
- `isAtEnd()`: Returns `this.currentFrame >= this.frames.length - 1`.

**Speed control:**
- `setSpeed(multiplier)`: Delegates to `this.timing.setSpeed()`.
- `getSpeed()`: Returns `this.timing.speed`.
- `getSpeedLabel()`: Delegates to `this.timing.getSpeedLabel()`.

**Private methods:**
- `_animate(currentTime)`: The rAF loop. If not playing, return. Call `this.timing.shouldAdvanceFrame(currentTime)`. If true, call stepForward(). If at end, pause. Schedule next frame with `this.rafId = requestAnimationFrame(this._animate.bind(this))`. Use arrow function or bind to preserve `this` context.
- `_dispatchFrameChange()`: Dispatches a `CustomEvent` named `'cpu:framechange'` on `window` with detail: `{ frame: this.currentFrame, state: this.frames[this.currentFrame], totalFrames: this.frames.length, isPlaying: this.isPlaying }`. Also calls `this.onFrameChange` callback if set.

**Visibility handling:**
- In constructor, add `document.addEventListener('visibilitychange', ...)` handler:
  - When tab becomes hidden and isPlaying: pause, set `this._pausedByVisibility = true`
  - When tab becomes visible and _pausedByVisibility: play, set `this._pausedByVisibility = false`
- This prevents rAF throttling issues per research pitfall #2.

**Edge cases:**
- `stepForward()` at last frame: returns false, no event dispatched
- `stepBackward()` at first frame: returns false, no event dispatched
- `loadFrames([])` or `loadFrames(null)`: sets frames to empty array, pauses, resets
- `play()` with no frames: does nothing
- Multiple rapid `play()` calls: idempotent (checks isPlaying first)

Export via `window.AnimationEngine = AnimationEngine;`. Wrap in IIFE. Assumes `window.TimingController` is available (loaded before this script).
