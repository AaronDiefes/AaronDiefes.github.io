# Plan 08-07: Navigation Redesign - Breadcrumbs + Simplified Structure

**Phase:** 8 - Visual Polish
**Created:** 2026-02-10
**Status:** Ready for execution

## Objective

Redesign site navigation to clearly communicate portfolio hierarchy using breadcrumbs and simplified top navigation. Replace current flat navigation (Portfolio | Demo | Documentation | Source Code) with a structure that shows "my website IS a portfolio, and all of the projects live inside this portfolio."

## Context

Current navigation treats all pages as siblings, which doesn't convey the portfolio → project → sub-pages hierarchy. Research shows breadcrumbs are best practice for 3+ level hierarchies and provide better mobile UX than complex dropdown menus.

**Research findings:**
- Breadcrumbs reduce cognitive load for hierarchical sites
- Mobile users perform 40% faster with clear navigation patterns
- WCAG 2.1 compliance requires clear site structure
- Best practice: Keep top nav simple (5-7 items max), use breadcrumbs for depth

## Success Criteria

- [ ] Top navigation is consistent across all 11 pages
- [ ] Breadcrumbs appear on all project-related pages (8 pages: demo, admin, 6 docs)
- [ ] Homepage navigation clearly shows "Projects" section
- [ ] Current page/section visually distinct in both nav and breadcrumbs
- [ ] Mobile hamburger menu updated with new structure
- [ ] Navigation communicates portfolio → Graphics Engine project → sub-pages hierarchy
- [ ] All links functional and pointing to correct paths
- [ ] ARIA attributes updated for accessibility

## Implementation Plan

### Task 1: Create Breadcrumb Component (30 min)

**Create:** `docs/assets/css/breadcrumbs.css`

**Content:**
```css
/* Breadcrumb navigation component */
.breadcrumbs {
  display: flex;
  align-items: center;
  gap: var(--space-xs, 0.5rem);
  padding: var(--space-sm, 0.75rem) 0;
  font-size: 0.875rem;
  color: var(--color-text-secondary, #666);
  flex-wrap: wrap;
}

.breadcrumbs ol {
  display: flex;
  align-items: center;
  gap: var(--space-xs, 0.5rem);
  list-style: none;
  padding: 0;
  margin: 0;
  flex-wrap: wrap;
}

.breadcrumbs li {
  display: flex;
  align-items: center;
  gap: var(--space-xs, 0.5rem);
}

.breadcrumbs a {
  color: var(--color-primary, #2E7D32);
  text-decoration: none;
  transition: color var(--timing-instant, 150ms) ease;
}

.breadcrumbs a:hover {
  color: var(--color-primary-dark, #1B5E20);
  text-decoration: underline;
}

.breadcrumbs a:focus-visible {
  outline: 2px solid var(--color-primary, #2E7D32);
  outline-offset: 2px;
  border-radius: 2px;
}

.breadcrumbs .separator {
  color: var(--color-text-secondary, #666);
  user-select: none;
}

.breadcrumbs [aria-current="page"] {
  color: var(--color-text-primary, #2c3e50);
  font-weight: 500;
}

/* Mobile adjustments */
@media (max-width: 480px) {
  .breadcrumbs {
    font-size: 0.8125rem;
    padding: var(--space-xs, 0.5rem) 0;
  }
}
```

**Validation:**
- Uses design system tokens
- ARIA-compliant with aria-current="page"
- Responsive for mobile
- Accessible focus states

**For each page, add breadcrumb HTML after nav, before main content:**

```html
<nav class="breadcrumbs" aria-label="Breadcrumb">
  <ol>
    <li><a href="[path-to-root]/index.html">Home</a></li>
    <li><span class="separator" aria-hidden="true">›</span></li>
    <li><a href="[path-to-root]/wasm-graphics-demo.html">Graphics Engine</a></li>
    <li><span class="separator" aria-hidden="true">›</span></li>
    <li><span aria-current="page">[Current Page Name]</span></li>
  </ol>
</nav>
```

**Breadcrumb paths by page:**
- Demo pages: Home › Graphics Engine › Interactive Demo
- Admin page: Home › Graphics Engine › Source Code
- Docs index: Home › Graphics Engine › Documentation
- Specific doc pages: Home › Graphics Engine › Documentation › [Page Name]

**Link breadcrumbs.css:**
- Root pages: `<link rel="stylesheet" href="docs/assets/css/breadcrumbs.css">`
- Docs pages: `<link rel="stylesheet" href="assets/css/breadcrumbs.css">`

**Validation:**
- Correct relative paths for all links

- Proper nesting order
- Links functional from all locations
