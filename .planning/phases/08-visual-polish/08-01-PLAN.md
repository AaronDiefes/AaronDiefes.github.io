  <files>docs/assets/css/design-system.css</files>
  <action>
Create `docs/assets/css/design-system.css` as the single source of truth for all visual tokens. Define the following CSS custom properties in `:root`:

**Colors (unified green palette per user decision):**
- `--color-primary: #2E7D32` (forest green, AA contrast 4.98:1 on white)
- `--color-primary-dark: #1B5E20` (dark forest green, AA contrast 8.59:1 on white)
- `--color-accent: #4CAF50` (light green, for dark backgrounds only)
- `--color-accent-light: #81C784` (pastel green, borders/subtle highlights)
- `--color-surface: #ffffff`
- `--color-surface-alt: #f8f9fa`
- `--color-surface-dim: #f5f5f5`
- `--color-text: #333333`
- `--color-text-heading: #2c3e50`
- `--color-text-muted: #666666`
- `--color-text-light: #555555`
- `--color-border: #e0e0e0`
- `--color-border-light: #dddddd`
- `--color-code-bg: #1e1e1e`
- `--color-footer-bg: #2c3e50`

**Gradients:**
- `--gradient-primary: linear-gradient(135deg, #2E7D32 0%, #1B5E20 100%)`
- `--gradient-header: linear-gradient(135deg, #2c3e50 0%, #34495e 100%)`

**Spacing (Fibonacci-based rem scale):**
- `--space-xs: 0.5rem` (8px)
- `--space-sm: 0.75rem` (12px)
- `--space-md: 1.25rem` (20px)
- `--space-lg: 2rem` (32px)
- `--space-xl: 3.25rem` (52px)

**Typography (system font stack, fluid sizing with clamp):**
- `--font-body: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Oxygen, Ubuntu, Cantarell, sans-serif`
- `--font-mono: 'Monaco', 'Menlo', 'Ubuntu Mono', 'Consolas', monospace`
- `--text-xs: clamp(0.75rem, 0.7rem + 0.25vw, 0.875rem)`
- `--text-sm: clamp(0.875rem, 0.8rem + 0.4vw, 1rem)`
- `--text-base: clamp(1rem, 0.95rem + 0.25vw, 1.125rem)`
- `--text-lg: clamp(1.125rem, 1rem + 0.6vw, 1.5rem)`
- `--text-xl: clamp(1.5rem, 1.2rem + 1.5vw, 2.5rem)`
- `--leading-body: 1.6`
- `--leading-heading: 1.2`
- `--leading-code: 1.4`

**Animation timing:**
- `--timing-instant: 150ms`
- `--timing-standard: 250ms`
- `--timing-complex: 350ms`
- `--easing-standard: ease`
- `--easing-enter: ease-out`
- `--easing-exit: ease-in`

**Also include the prefers-reduced-motion media query at the bottom:**
```css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```

Keep the file clean and well-commented with section headers. No component styles - tokens only.
