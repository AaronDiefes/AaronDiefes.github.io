   - What is a KD-tree: k-dimensional binary search tree for spatial partitioning
   - Why KD-trees for ride-sharing: O(log n) nearest-neighbor vs O(n) brute force
   - 2D context: latitude and longitude coordinates for driver/rider locations
   - Time complexities: construction O(n log n), query O(log n) average, O(n) worst case

2. **Node Structure Section (CODE-03):**
   - Explain the KDNode data structure

     ```
     class KDNode:
         def __init__(self, point, axis, left=None, right=None):
             self.point = point       # (lat, lon) tuple
             self.axis = axis         # 0=latitude, 1=longitude
             self.left = left         # points < median on axis
             self.right = right       # points >= median on axis
     ```
   - Use span-based highlighting: `class` and `def` as `.keyword`, `self`, `point`, `axis` as `.signal`, `None` as `.keyword`, `=` as `.operator`
   - Inline annotations on each attribute explaining its purpose
   - Explain axis alternation: depth 0 splits on latitude, depth 1 on longitude, etc.

3. **Tree Construction Section (CODE-02):**
   - Explain recursive median-split construction algorithm
   - Complexity badge: O(n log n)
   - Python code block showing `build_kdtree(points, depth=0)` function:
     - Base case: empty list returns None
     - Calculate axis from depth modulo 2
     - Sort points by current axis coordinate
     - Find median index
     - Create node with median point
     - Recursively build left subtree (points before median)
     - Recursively build right subtree (points after median)
   - Inline annotations explaining median selection and axis alternation
   - Explain why median splitting creates a balanced tree

4. **Nearest Neighbor Search Section (CODE-02):**
   - Explain the search algorithm: traverse tree, prune branches that can't contain closer points
   - Complexity badge: O(log n) average
   - Python code block showing `find_nearest(node, target, best=None, best_dist=float('inf'))` function:
     - Base case: node is None, return best
     - Compute distance from target to current node's point
     - Update best if current is closer
     - Determine which subtree to search first (same side as target)
     - Recursively search near subtree
     - Check if far subtree could contain closer point (distance to splitting plane < best_dist)
     - If so, recursively search far subtree
   - Inline annotations on the pruning decision (key optimization)
   - Explain the splitting plane distance check and why it enables O(log n)

5. **Ride-Sharing Integration Section:**
   - Show how KD-tree integrates into the matching system
   - Python code block showing `match_with_kdtree(riders, drivers)` function:
     - Extract driver locations as points
     - Build KD-tree from driver points
     - For each rider, find nearest available driver using tree query
     - Mark matched drivers as unavailable (remove from consideration)
   - Inline annotations explaining the matching workflow
   - Explain limitation: after matching, tree may need rebuilding or use of alternative removal strategy
   - Note connection to T4 algorithm from Algorithm Evolution page (link to `/projects/cs330/docs/algorithm`)
