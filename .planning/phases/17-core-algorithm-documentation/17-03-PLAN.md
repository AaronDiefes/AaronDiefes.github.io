1. **Overview Section:**
   - Why pathfinding matters: Euclidean distance is inaccurate for road-based travel

   - Dijkstra's algorithm: finds shortest path in weighted graph with non-negative edges
   - Time complexity: O((V + E) log V) with binary heap priority queue

2. **Graph Representation Section (CODE-03):**

     ```
     import networkx as nx

     def build_road_network(intersections, roads):
         graph = nx.Graph()
         for node_id, lat, lon in intersections:
             graph.add_node(node_id, lat=lat, lon=lon)
         for start, end, distance in roads:
             graph.add_edge(start, end, weight=distance)
         return graph
     ```
   - Inline annotations explaining node attributes and edge weights
   - Explain Haversine distance for edge weight calculation

3. **Haversine Distance Section:**
   - Explain: Great-circle distance between two lat/lon points on Earth
   - Python code block showing `haversine_distance(lat1, lon1, lat2, lon2)` function:
     - Convert degrees to radians
     - Apply Haversine formula: `a = sin(dlat/2)**2 + cos(lat1)*cos(lat2)*sin(dlon/2)**2`
     - `c = 2 * asin(sqrt(a))`
     - `distance = R * c` where R = 6371 km (Earth radius)
   - Inline annotations explaining each step of the formula
   - Why Haversine is needed: flat Euclidean fails for geographic coordinates

4. **Dijkstra's Algorithm Section (CODE-02):**
   - Explain the algorithm step by step: initialize distances, use priority queue, relax edges
   - Complexity badge: O((V + E) log V)
   - Python code block showing `dijkstra_shortest_path(graph, source, target)` function:
     - Initialize distances dict: all nodes to infinity, source to 0
     - Priority queue (min-heap) with `heapq`: push (0, source)
     - While queue not empty:
       - Pop minimum distance node
       - If node is target, return distance and path
       - Skip if already visited (distance > known distance)
       - For each neighbor, compute new distance through current node
       - If shorter, update distance and push to queue
     - Track predecessors for path reconstruction
   - Inline annotations on: priority queue pop, relaxation step, early termination, path reconstruction
   - Explain: why Dijkstra requires non-negative weights, connection to greedy strategy

5. **Priority Queue Section (CODE-03):**
   - Explain Python's `heapq` module for min-heap operations
   - Python code block showing priority queue usage patterns:
     - `heapq.heappush(queue, (distance, node_id))`
     - `distance, node = heapq.heappop(queue)`
     - Explain tuple comparison: first element (distance) determines priority
   - Inline annotations explaining heap operations and time complexity
   - Explain: O(log n) push/pop vs O(n) for unsorted list
