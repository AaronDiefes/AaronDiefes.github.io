  <action>
    Create `scripts/run_cs330_analysis.py` that:

    1. **Sets up Python path** to import from CS330 submodule:
       ```python
       import sys
       import os
       sys.path.insert(0, os.path.join(os.path.dirname(__file__), 'cs330-case-study'))
       ```

    2. **Imports CS330 algorithm implementations:**
       - Import T1_Matcher through T5_Matcher from algorithms module
       - Import utility functions from utils module
       - Import matplotlib.pyplot and numpy

    3. **Runs simulations and captures metrics** for each algorithm (T1-T5):
       - For each algorithm (T1 through T5):
         - Instantiate the matcher (e.g., `t1 = T1_Matcher()`)
         - Run a simplified matching simulation (match first 100 riders to extract metrics)
         - Extract metrics from the matcher object:
           - `average_d1 = matcher.d1 / matcher.total_rides_completed`
           - `average_d2 = matcher.d2 / matcher.total_rides_completed`
           - `runtime = matcher.get_closest_total_time + matcher.get_shortest_path_total_time`
         - Store in a metrics dictionary

    4. **Saves metrics to JSON**:
       ```python
       import json
       with open('scripts/cs330_metrics.json', 'w') as f:
           json.dump(metrics, f, indent=2)
       ```

    5. **Generates 5 comparison graphs** using matplotlib:

       **Graph 1: D1 Comparison (d1_comparison.png)**
       - Line graph with markers showing Average D1 for T1-T5
       - X-axis: Algorithm names ['T1\nBrute Force', 'T2\nSorted', ...]
       - Y-axis: Average D1 (km)
       - Color: Portfolio green (#2E7D32)
       - Annotate values on each point
       - Title: "D1 Performance Evolution: Real Algorithm Comparison"
       - Save: `public/projects/cs330/images/d1_comparison.png` (dpi=150)

       **Graph 2: D2 Comparison (d2_comparison.png)**
       - Line graph showing Average D2 for T1-T5
       - Same style as D1 but using PORTFOLIO_DARK_GREEN (#1B5E20)
       - Title: "D2 Performance Evolution: Real Algorithm Comparison"
       - Save: `public/projects/cs330/images/d2_comparison.png` (dpi=150)

       **Graph 3: D1/D2 Combined (d1_d2_combined.png)**
       - Grouped bar chart comparing D1 and D2 side by side
       - Two bars per algorithm (D1 in green, D2 in dark green)
       - Title: "D1 vs D2 Performance Comparison"
       - Save: `public/projects/cs330/images/d1_d2_combined.png` (dpi=150)

       **Graph 4: Runtime Comparison (runtime_comparison.png)**
       - Bar chart showing total runtime for each algorithm
       - Green bars for fast algorithms (<500ms), orange for slower
       - Value labels on top of bars
       - Title: "Algorithm Runtime Comparison"
       - Save: `public/projects/cs330/images/runtime_comparison.png` (dpi=150)

       **Graph 5: Supply-Demand Scatter (supply_demand_distribution.png)**
       - Access rider/driver location data from one of the matchers
       - Scatter plot: riders (red circles), drivers (green triangles)
       - Use first 100 riders and 50 drivers from the simulation data
       - Title: "Supply-Demand Spatial Distribution"
       - Save: `public/projects/cs330/images/supply_demand_distribution.png` (dpi=150)

    **Styling requirements:**
    - All graphs: `plt.style.use('seaborn-v0_8-whitegrid')` with try/except fallback
    - Figure size: (10, 6)
    - Font sizes: axes labels 12pt, title 14pt, legend 10pt
    - Portfolio colors: #2E7D32 (green), #1B5E20 (dark green), #d32f2f (red)
    - DPI: 150 for retina quality
    - White background: `facecolor='white'`

    **Error handling:**
    - Wrap imports in try/except to provide helpful error messages if CS330 submodule isn't initialized
