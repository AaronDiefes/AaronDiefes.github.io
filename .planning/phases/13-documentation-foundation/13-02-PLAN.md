**Component structure:**
1. Breadcrumbs: Home > CPU Simulator > Documentation > ALU Design

3. **Section: What is an ALU?**
   - The Arithmetic Logic Unit is the computational core of the CPU
   - It performs arithmetic (add, subtract) and logic operations on 32-bit operands
   - In our 5-stage pipeline, the ALU operates in the Execute (EX) stage
   - The ALU receives two operands and an operation selector, and produces a result and status flags

4. **Section: The Problem with Ripple-Carry**
   - Explain ripple-carry adder: each bit's carry depends on the previous bit, creating a chain
   - For a 32-bit adder, worst case is 32 gate delays for carry to propagate from LSB to MSB
   - Show simple ripple-carry Verilog:
     ```verilog
     // Ripple-Carry Adder (slow - O(n) delay)
     // Each full adder waits for carry from previous stage
     assign {c[1], sum[0]} = a[0] + b[0] + cin;
     assign {c[2], sum[1]} = a[1] + b[1] + c[1];
     // ... carry ripples through all 32 bits
     assign {cout, sum[31]} = a[31] + b[31] + c[31];
     ```
   - This O(n) delay is the bottleneck - can we do better?

5. **Section: Carry-Lookahead Concept**
   - Define Generate (G) and Propagate (P) signals:
     - G_i = a_i AND b_i (bit i generates a carry regardless of input carry)
     - P_i = a_i XOR b_i (bit i propagates an incoming carry)
   - Show that carries can be computed directly:
     - C_1 = G_0 OR (P_0 AND C_0)
     - C_2 = G_1 OR (P_1 AND G_0) OR (P_1 AND P_0 AND C_0)
     - Each carry depends only on G, P, and C_0 - computed in O(1) levels of logic
   - Show Verilog for generate and propagate:
     ```verilog
     // Generate and Propagate signals
     assign generate = a & b;      // G_i = a_i AND b_i
     assign propagate = a ^ b;     // P_i = a_i XOR b_i
     ```

6. **Section: 4-Bit CLA Block**
   - Show the core 4-bit Carry-Lookahead Adder module in Verilog:
     ```verilog
     module cla_4bit(
         input  [3:0] a, b,
         input        cin,
         output [3:0] sum,
         output       cout,
         output       group_generate,
         output       group_propagate
     );
         wire [3:0] g, p;
         wire [4:0] c;

         // Generate and Propagate
         assign g = a & b;
         assign p = a ^ b;

         // Carry Lookahead Logic
         assign c[0] = cin;
         assign c[1] = g[0] | (p[0] & c[0]);
         assign c[2] = g[1] | (p[1] & g[0]) | (p[1] & p[0] & c[0]);
         assign c[3] = g[2] | (p[2] & g[1]) | (p[2] & p[1] & g[0])
                      | (p[2] & p[1] & p[0] & c[0]);
         assign c[4] = g[3] | (p[3] & g[2]) | (p[3] & p[2] & g[1])
                      | (p[3] & p[2] & p[1] & g[0])
                      | (p[3] & p[2] & p[1] & p[0] & c[0]);

         // Sum computation
         assign sum = p ^ c[3:0];
         assign cout = c[4];

         // Group signals for hierarchical CLA
         assign group_generate = g[3] | (p[3] & g[2]) | (p[3] & p[2] & g[1])
                               | (p[3] & p[2] & p[1] & g[0]);
         assign group_propagate = p[3] & p[2] & p[1] & p[0];
     endmodule
     ```

7. **Section: 32-Bit Hierarchical CLA**
   - Explain: to build a 32-bit adder, chain eight 4-bit CLA blocks using group generate/propagate signals
   - The second level of lookahead computes carries between 4-bit groups in parallel
   - Total delay: O(log n) instead of O(n) - for 32 bits, about 4 gate levels vs 32
   - Show the 32-bit module structure in Verilog:
     ```verilog
     module cla_32bit(
         input  [31:0] a, b,
         input         cin,
         output [31:0] sum,
         output        cout
     );
         wire [7:0] group_g, group_p;
         wire [8:0] group_c;

         // Eight 4-bit CLA blocks
         cla_4bit block0(.a(a[3:0]),   .b(b[3:0]),   .cin(group_c[0]),
                         .sum(sum[3:0]),   .group_generate(group_g[0]),
                         .group_propagate(group_p[0]));
         cla_4bit block1(.a(a[7:4]),   .b(b[7:4]),   .cin(group_c[1]),
                         .sum(sum[7:4]),   .group_generate(group_g[1]),
                         .group_propagate(group_p[1]));
         // ... blocks 2-7 follow same pattern

         // Second-level lookahead
         assign group_c[0] = cin;
         assign group_c[1] = group_g[0] | (group_p[0] & group_c[0]);
         assign group_c[2] = group_g[1] | (group_p[1] & group_g[0])
                            | (group_p[1] & group_p[0] & group_c[0]);
         // ... continues for all 8 groups

         assign cout = group_c[8];
     endmodule
     ```

8. **Section: ALU Operations**
   - Show the complete ALU module that uses the CLA for addition:
     ```verilog
     module alu(
         input  [31:0] operand_a, operand_b,
         input  [3:0]  alu_op,
         output [31:0] result,
         output        zero
     );
         wire [31:0] add_result, sub_result;

         // CLA adder for ADD
         cla_32bit adder(.a(operand_a), .b(operand_b),
                         .cin(1'b0), .sum(add_result));
         // Subtraction via two's complement
         cla_32bit subtractor(.a(operand_a), .b(~operand_b),
                              .cin(1'b1), .sum(sub_result));

         // Operation multiplexer
         assign result = (alu_op == 4'b0010) ? add_result :   // ADD
                         (alu_op == 4'b0110) ? sub_result :   // SUB
                         32'b0;

         assign zero = (result == 32'b0);
     endmodule
     ```
