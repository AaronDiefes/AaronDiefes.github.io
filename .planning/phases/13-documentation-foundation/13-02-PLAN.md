**Content sections (each in a `.section` div):**

1. **Overview** - What the ALU does:
   - The ALU is the computational core of the processor
   - Takes two 32-bit inputs (data_operandA, data_operandB) and a 5-bit ALU opcode
   - Produces a 32-bit result and status flags (overflow, not-equal, less-than)
   - Supports: add, subtract, AND, OR, SLL, SRA

2. **Carry-Lookahead Adder** - The key design:
   - Why CLA over ripple-carry: O(log n) vs O(n) delay
   - Generate (G) and Propagate (P) signals: G_i = A_i AND B_i, P_i = A_i XOR B_i
   - Group generate/propagate for 4-bit blocks
   - Two-level CLA: 8 blocks of 4 bits each for 32-bit addition
   - Show the carry equations: C1 = G0 + P0*C0, C2 = G1 + P1*G0 + P1*P0*C0, etc.

   Include Verilog code snippet for the CLA block (representative, educational):
   ```verilog
   // 4-bit CLA block - Generate and Propagate
   wire [3:0] g, p;
   assign g = A & B;           // Generate: both bits are 1
   assign p = A ^ B;           // Propagate: one bit is 1

   // Carry lookahead equations
   assign c[1] = g[0] | (p[0] & c[0]);
   assign c[2] = g[1] | (p[1] & g[0]) | (p[1] & p[0] & c[0]);
   assign c[3] = g[2] | (p[2] & g[1]) | (p[2] & p[1] & g[0])
                       | (p[2] & p[1] & p[0] & c[0]);
   ```

3. **ALU Operations** - Table of supported operations:
   - ALU opcode 00000: ADD (uses CLA)
   - ALU opcode 00001: SUB (2's complement: A + ~B + 1)
   - ALU opcode 00010: AND (bitwise)
   - ALU opcode 00011: OR (bitwise)
   - ALU opcode 00100: SLL (shift left logical)
   - ALU opcode 00101: SRA (shift right arithmetic)

   Include Verilog snippet showing the ALU top-level mux:
   ```verilog
   // ALU operation select
   wire [31:0] add_result, sub_result, and_result, or_result, sll_result, sra_result;

   assign and_result = data_operandA & data_operandB;
   assign or_result  = data_operandA | data_operandB;
   assign sll_result = data_operandA << ctrl_shiftamt;
   assign sra_result = $signed(data_operandA) >>> ctrl_shiftamt;
   ```

4. **Overflow Detection** - How overflow is detected for add/sub:
   - Overflow occurs when the sign of the result doesn't match expected sign
   - For addition: overflow = (A[31] == B[31]) && (result[31] != A[31])
   - For subtraction: overflow uses the carry out of the MSB XOR carry into MSB

   Include Verilog snippet:
   ```verilog
   // Overflow detection for addition
   assign overflow = (data_operandA[31] == data_operandB[31])
                   & (add_result[31] != data_operandA[31]);
   ```

5. **Status Flags**:
   - isNotEqual: result != 0 (output of OR reduction)
   - isLessThan: checks sign bit with overflow consideration
