   - Explain the concept: pipelining allows multiple instructions to execute simultaneously by breaking execution into stages, like an assembly line
   - Use a laundry analogy: washing, drying, folding - you don't wait for one load to finish all steps before starting the next
   - Explain throughput vs latency: pipelining improves throughput (instructions per cycle) without reducing latency (time for one instruction)

4. **Section: The 5 Pipeline Stages**
   - For each stage, provide a subsection with:
     - **Instruction Fetch (IF):** Reads instruction from memory at address PC, increments PC by 4. Show Verilog snippet:
       ```verilog
       // Instruction Fetch Stage
       always @(posedge clk) begin
           if (!stall) begin
               instruction <= instruction_memory[PC >> 2];
               PC_next <= PC + 4;
           end
       end
       ```
     - **Instruction Decode (ID):** Reads register file, extends immediates, determines control signals. Show Verilog:
       ```verilog
       // Instruction Decode - Register File Read
       assign read_data1 = (rs == 5'b0) ? 32'b0 : registers[rs];
       assign read_data2 = (rt == 5'b0) ? 32'b0 : registers[rt];
       // Sign-extend immediate
       assign sign_extended = {{16{immediate[15]}}, immediate};
       ```
     - **Execute (EX):** ALU performs operation. Show Verilog:
       ```verilog
       // ALU Operation Selection
       always @(*) begin
           case (alu_op)
               4'b0010: alu_result = operand_a + operand_b;  // ADD
               4'b0110: alu_result = operand_a - operand_b;  // SUB
               default: alu_result = 32'b0;
           endcase
       end
       ```
     - **Memory Access (MEM):** Load/store data memory. Show Verilog:
       ```verilog
       // Data Memory Access
       always @(posedge clk) begin
           if (mem_write)
               data_memory[alu_result >> 2] <= write_data;
       end
       assign mem_read_data = data_memory[alu_result >> 2];
       ```
     - **Writeback (WB):** Write result back to register file. Show Verilog:
       ```verilog
       // Register Writeback
       always @(posedge clk) begin
           if (reg_write && write_reg != 5'b0)
               registers[write_reg] <= write_data;
       end
       ```

5. **Section: Pipeline Registers**
   - Explain that pipeline registers (IF/ID, ID/EX, EX/MEM, MEM/WB) store intermediate values between stages
   - Show a Verilog snippet for a pipeline register:
     ```verilog

     always @(posedge clk) begin
         if (!stall) begin
             IF_ID_instruction <= instruction;
             IF_ID_PC <= PC_next;
         end
     end
     ```

6. **Section: See It In Action**
