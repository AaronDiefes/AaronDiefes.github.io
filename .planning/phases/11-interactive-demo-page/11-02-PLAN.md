  <name>Task 1: Create ControlPanel component</name>
  <files>cpu-simulator/src/ui/control-panel.js</files>
  <action>
Create the ControlPanel class that wraps AnimationEngine with HTML button/select controls.

**ControlPanel (control-panel.js):**
- Class ControlPanel with constructor(container, engine) where engine is an AnimationEngine instance
- constructor:
  - Store references to container and engine
  - Call _createControls() to build DOM
  - Listen to 'cpu:framechange' event on window to call _updateButtonStates()
  - Call _updateButtonStates() initially
- _createControls() method that builds this HTML structure inside container:
  ```html
  <div class="control-panel">
    <div class="control-group playback-controls">
      <button class="btn-reset" aria-label="Reset to start" title="Reset (R)">Reset</button>
      <button class="btn-step-back" aria-label="Step backward" title="Step Back (Left Arrow)">Step Back</button>
      <button class="btn-play-pause" aria-label="Play" title="Play/Pause (Space)">Play</button>
      <button class="btn-step-forward" aria-label="Step forward" title="Step Forward (Right Arrow)">Step Fwd</button>
    </div>
    <div class="control-group speed-controls">
      <label for="speed-select">Speed:</label>
      <select id="speed-select" aria-label="Playback speed">
        <option value="0.25">0.25x</option>
        <option value="0.5">0.5x</option>
        <option value="1" selected>1x</option>
        <option value="2">2x</option>
        <option value="4">4x</option>
      </select>
    </div>
    <div class="control-group status-display">
      <span class="frame-status" aria-live="polite">Frame 0 of 0</span>
    </div>
  </div>
  ```
- Wire button click handlers:
  - .btn-reset → engine.reset()
  - .btn-step-back → engine.stepBackward()
  - .btn-play-pause → engine.togglePlayPause()
  - .btn-step-forward → engine.stepForward()
  - #speed-select → engine.setSpeed(parseFloat(value))
- Use querySelector with CSS class selectors (NOT getElementById) to find buttons within this.container, avoiding ID collisions if multiple instances exist.
- _updateButtonStates() method that:
  - Updates play/pause button text: "Pause" when engine.isPlaying, "Play" otherwise
  - Updates play/pause button aria-label accordingly
  - Disables .btn-step-back when engine.isAtStart()
  - Disables .btn-step-forward when engine.isAtEnd()
  - Updates frame status: "Frame {current} of {total - 1}" using engine.getProgress()
  - When total is 0, show "No frames loaded"
- destroy() method: remove event listener, clear container innerHTML
- Export as window.ControlPanel via IIFE pattern

**Important design notes:**
- Use CSS class selectors instead of ID selectors for buttons to avoid ID collisions
- Buttons should use semantic `<button>` elements with ARIA labels
- Frame status uses aria-live="polite" for screen reader announcements
- Title attributes show keyboard shortcuts

<task type="auto">
  <name>Task 2: Create ProgramSelector component</name>
  <files>cpu-simulator/src/ui/program-selector.js</files>
  <action>
Create the ProgramSelector class that manages program switching and frame generation.

**ProgramSelector (program-selector.js):**
- Class ProgramSelector with constructor(container, engine, options) where:
  - engine: AnimationEngine instance
  - options: optional object with:
    - onProgramLoad: callback(program, result) called after program loads (for updating InstructionList, CPUVisualizer, etc.)
    - defaultProgram: string key (default: 'basic')
- constructor:
  - Store references to container, engine, and callbacks
  - Build programs map from window.CPU_PROGRAMS if it exists, otherwise fallback:
    ```javascript
    this.programs = window.CPU_PROGRAMS || {
      basic: window.BASIC_PROGRAM,
      fibonacci: window.FIBONACCI_PROGRAM
    };
    ```
  - Call _createSelector() to build DOM
  - Call _loadProgram() with default program key
- _createSelector() method that builds HTML:
  ```html
  <div class="program-selector">
    <label for="program-select">Program:</label>
    <select class="program-select" aria-label="Select program">
      <!-- options populated from this.programs -->
    </select>
    <p class="program-description"></p>
  </div>
  ```
  - Populate select options by iterating over this.programs entries, using program.name as option text and key as value
  - Wire change handler to call _loadProgram(selectedValue)
- _loadProgram(programKey) method that:
  - Gets program from this.programs[programKey]
  - If program not found, log error and return
  - Generates frames: const result = SequenceGenerator.generateSequence(program.instructions)
  - Loads frames into engine: this.engine.loadFrames(result.frames)
  - Updates description paragraph with program.description
  - Calls onProgramLoad callback if provided: this.onProgramLoad(program, result)
  - Logs: console.log(`Loaded: ${program.name} (${result.frames.length} frames)`)
- getCurrentProgram() getter returning current program object
- getCurrentProgramKey() getter returning current key string
- Export as window.ProgramSelector via IIFE pattern

**Important design notes:**
- Use CSS class selectors (not IDs) for the select element to avoid ID collisions
- The onProgramLoad callback is how the demo page wires InstructionList.loadProgram() and initial CPUVisualizer.render() - ProgramSelector does NOT have direct references to these components
- Programs come from Phase 9 globals (BASIC_PROGRAM, FIBONACCI_PROGRAM, CPU_PROGRAMS)
- SequenceGenerator is a Phase 9 global (window.SequenceGenerator)
