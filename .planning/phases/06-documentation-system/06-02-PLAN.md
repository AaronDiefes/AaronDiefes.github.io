**Section: GCanvas** (id="gcanvas")
Extract from GCanvas.h. Document these functions:
| Function | Parameters | Description |
|----------|------------|-------------|
| `GCreateCanvas(const GBitmap&)` | GBitmap - target bitmap | Factory: Creates canvas for drawing into bitmap |
| `void save()` | none | Save current CTM to stack |
| `void restore()` | none | Restore CTM from stack |
| `void concat(const GMatrix&)` | GMatrix - transformation matrix | Multiply CTM by matrix (CTM' = CTM * matrix) |
| `void clear(const GColor&)` | GColor - fill color | Fill entire canvas using kSrc blend mode |
| `void drawRect(const GRect&, const GPaint&)` | GRect bounds, GPaint style | Fill rectangle (pixel centers inside bounds) |
| `void drawConvexPolygon(const GPoint[], int, const GPaint&)` | GPoint[] vertices, count, GPaint | Fill convex polygon with edge-list algorithm |
| `void drawPath(const GPath&, const GPaint&)` | GPath path, GPaint style | Fill path using winding-fill rule |
| `void drawMesh(const GPoint[], const GColor[], const GPoint[], int, const int[], const GPaint&)` | verts, colors, texs, count, indices, GPaint | Draw indexed triangle mesh |
| `void drawQuad(const GPoint[4], const GColor[4], const GPoint[4], int, const GPaint&)` | corners, colors, texs, level, GPaint | Draw subdivided quad (2^level triangles) |
| `void translate(float, float)` | x, y offset | Helper: concat(Translate(x,y)) |
| `void scale(float, float)` | x, y scale factors | Helper: concat(Scale(x,y)) |
| `void rotate(float)` | radians | Helper: concat(Rotate(radians)) |

Include usage example code block:
```cpp
GBitmap bitmap;
bitmap.alloc(800, 600);
auto canvas = GCreateCanvas(bitmap);

canvas->clear(GColor::RGBA(1, 1, 1, 1));  // white background

GPaint paint;
paint.setColor(GColor::RGBA(1, 0, 0, 1));  // red
canvas->drawRect(GRect::LTRB(10, 10, 100, 100), paint);

canvas->save();
canvas->translate(200, 200);
canvas->rotate(M_PI / 4);  // 45 degrees
canvas->drawRect(GRect::LTRB(-50, -50, 50, 50), paint);
canvas->restore();
```
