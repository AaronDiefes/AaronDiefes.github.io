**Section 1: Edge-List Rasterization**

*Mathematical Foundation:*
```
Each polygon edge is represented as a line: x = m * y + b
Where:
  m = (x1 - x0) / (y1 - y0)  (inverse slope)
  b = x0 - m * y0            (x-intercept)

For pixel-center sampling at row y:
  x_intersection = m * (y + 0.5) + b
```

*Algorithm Steps:*
1. Convert polygon vertices to edges (clip to canvas bounds)
2. Store each edge with: top_y, bottom_y, current_x, slope_m
3. Sort edges by top_y (ascending)
4. For each scanline y from min_y to max_y:
   a. Add edges where top_y == y to active edge list
   b. Compute x intersection for each active edge
   c. Sort active edges by x intersection
   d. Fill between pairs of intersections (even-odd)
   e. Remove edges where bottom_y == y
   f. Update current_x for remaining edges: x += m

*C++ Implementation:*
```cpp
// Edge structure from Edge.h
struct Edge {
    int top, bottom;    // Y bounds (exclusive bottom)
    float curX;         // Current X intersection
    float slope;        // Change in X per scanline (m = dx/dy)

    // Initialize edge from two points
    void init(GPoint p0, GPoint p1, int clipTop, int clipBottom);

    // Compute X at given Y (for initial position)
    float eval(int y) const {
        return slope * ((float)y + 0.5f) + curX;
    }
};

// Scanline filling (simplified)
void drawConvexPolygon(const GPoint pts[], int count, const GPaint& paint) {
    std::vector<Edge> edges;

    // 1. Build edges from consecutive vertices
    for (int i = 0; i < count; i++) {
        Edge e;
        if (e.init(pts[i], pts[(i+1) % count], 0, height)) {
            edges.push_back(e);
        }
    }

    // 2. Sort by top Y
    std::sort(edges.begin(), edges.end(),
              [](const Edge& a, const Edge& b) { return a.top < b.top; });

    // 3. Process each scanline
    int nextEdge = 0;
    std::vector<Edge*> active;

    for (int y = edges[0].top; y < maxY; y++) {
        // Add new edges
        while (nextEdge < edges.size() && edges[nextEdge].top == y) {
            active.push_back(&edges[nextEdge++]);
        }

        // Sort active by X
        std::sort(active.begin(), active.end(),
                  [](Edge* a, Edge* b) { return a->curX < b->curX; });

        // Fill between pairs
        for (int i = 0; i + 1 < active.size(); i += 2) {
            int x0 = GRoundToInt(active[i]->curX);
            int x1 = GRoundToInt(active[i+1]->curX);
            blitRow(y, x0, x1, paint);
        }

        // Update and remove edges
        for (auto it = active.begin(); it != active.end(); ) {
            (*it)->curX += (*it)->slope;
            if (y + 1 >= (*it)->bottom) {
                it = active.erase(it);
            } else {
                ++it;
            }
        }
    }
}
```

**Section 2: Matrix Transformation Math**

*Mathematical Foundation:*
```
2D affine transformation uses 3x3 matrix (homogeneous coordinates):
| a  b  tx |   | x |   | a*x + b*y + tx |
| c  d  ty | * | y | = | c*x + d*y + ty |
| 0  0  1  |   | 1 |   |       1        |

Common transformations:
Translate(tx, ty):     | 1  0  tx |
                       | 0  1  ty |

Scale(sx, sy):         | sx  0  0 |
                       |  0 sy  0 |

Rotate(θ):             | cos(θ) -sin(θ) 0 |
                       | sin(θ)  cos(θ) 0 |

Matrix concatenation (A * B) applies B first, then A.
CTM' = CTM * localMatrix  (pre-concatenation)
```

*Algorithm: Matrix Inversion*
```
For 2D affine matrix [a b tx; c d ty]:
det = a*d - b*c

If det == 0, matrix is singular (no inverse)

Inverse:
| a' b' tx' |     1     |  d  -b  (b*ty - d*tx) |
| c' d' ty' | = ----- * | -c   a  (c*tx - a*ty) |
                det
```

*C++ Implementation:*
```cpp
// From GMatrix.cpp
bool GMatrix::invert(GMatrix* inverse) const {
    float det = fMat[0] * fMat[4] - fMat[1] * fMat[3];
    if (det == 0) {
        return false;  // Singular matrix
    }

    float invDet = 1.0f / det;
    inverse->fMat[0] =  fMat[4] * invDet;
    inverse->fMat[1] = -fMat[1] * invDet;
    inverse->fMat[2] = (fMat[1] * fMat[5] - fMat[4] * fMat[2]) * invDet;
    inverse->fMat[3] = -fMat[3] * invDet;
    inverse->fMat[4] =  fMat[0] * invDet;
    inverse->fMat[5] = (fMat[3] * fMat[2] - fMat[0] * fMat[5]) * invDet;
    return true;
}

void GMatrix::mapPoints(GPoint dst[], const GPoint src[], int count) const {
    for (int i = 0; i < count; i++) {
        float x = src[i].x;
        float y = src[i].y;
        dst[i].x = fMat[0] * x + fMat[1] * y + fMat[2];
        dst[i].y = fMat[3] * x + fMat[4] * y + fMat[5];
    }
}
```

**Section 3: Bezier Curve Tessellation**

*Mathematical Foundation:*
```
Quadratic Bezier: P(t) = (1-t)²P₀ + 2(1-t)tP₁ + t²P₂
Cubic Bezier:    P(t) = (1-t)³P₀ + 3(1-t)²tP₁ + 3(1-t)t²P₂ + t³P₃

Where t ∈ [0, 1] and P₀, P₁, P₂, (P₃) are control points.

Adaptive tessellation: Subdivide until curve is "flat enough"
Flatness heuristic: Maximum deviation of control points from line P₀→Pₙ
```

*Algorithm: Adaptive Subdivision*
```
function tessellate(P0, P1, P2, tolerance):
    # Calculate max deviation from chord
    chord = P2 - P0
    deviation = perpendicular_distance(P1, P0, P2)

    if deviation < tolerance:
        # Flat enough: emit line segment
        emit_line(P0, P2)
    else:
        # Subdivide: de Casteljau algorithm
        Q0 = P0
        Q1 = (P0 + P1) / 2
        Q2 = (P0 + 2*P1 + P2) / 4

        R0 = Q2
        R1 = (P1 + P2) / 2
        R2 = P2

        tessellate(Q0, Q1, Q2, tolerance)
        tessellate(R0, R1, R2, tolerance)
```

*C++ Implementation:*
```cpp
// From path_ops.h
void tessellateQuad(const GPoint pts[3], float tolerance, std::vector<GPoint>& output) {
    // Calculate flatness (max deviation from chord)
    GPoint d = pts[1] - (pts[0] + pts[2]) * 0.5f;
    float flatness = std::abs(d.x) + std::abs(d.y);  // Manhattan distance

    if (flatness <= tolerance) {
        // Flat enough: just emit endpoint
        output.push_back(pts[2]);
    } else {
        // Subdivide using de Casteljau
        GPoint left[3], right[3];

        left[0] = pts[0];
        left[1] = (pts[0] + pts[1]) * 0.5f;
        left[2] = (pts[0] + pts[1] * 2 + pts[2]) * 0.25f;

        right[0] = left[2];
        right[1] = (pts[1] + pts[2]) * 0.5f;
        right[2] = pts[2];

        tessellateQuad(left, tolerance, output);
        tessellateQuad(right, tolerance, output);
    }
}

// Cubic Bezier follows similar pattern with 4 control points
void tessellateCubic(const GPoint pts[4], float tolerance, std::vector<GPoint>& output);
```

**Section 4: Blend Function Optimization**

*Mathematical Foundation:*
```
Porter-Duff compositing formula for SrcOver:
  Result = Src + Dst * (1 - SrcAlpha)

In premultiplied alpha space:
  R.rgb = S.rgb + D.rgb * (255 - S.a) / 255
  R.a   = S.a   + D.a   * (255 - S.a) / 255

Integer approximation using 8.8 fixed point:
  x * (255 - a) / 255 ≈ x * (256 - a) >> 8  (slightly overestimates)
  Better: (x * (255 - a) + 127) / 255       (rounded)
```

*Optimization: Blend Function Selection*
```
Before blending, analyze paint to select optimal function:
1. If alpha == 0: use kDst (no-op)
2. If alpha == 255 and mode == kSrcOver: use kSrc (direct copy)
3. If alpha == 255 and mode == kSrc: use memcpy
4. Otherwise: use full blend function
```

*C++ Implementation:*
```cpp
// From blend_functions.h
inline GPixel blend_SrcOver(GPixel src, GPixel dst) {
    unsigned srcA = GPixel_GetA(src);
    if (srcA == 255) return src;
    if (srcA == 0) return dst;

    unsigned invSrcA = 255 - srcA;
    return GPixel_PackARGB(
        srcA + div255(GPixel_GetA(dst) * invSrcA),
        GPixel_GetR(src) + div255(GPixel_GetR(dst) * invSrcA),
        GPixel_GetG(src) + div255(GPixel_GetG(dst) * invSrcA),
        GPixel_GetB(src) + div255(GPixel_GetB(dst) * invSrcA)
    );
}

// Fast divide by 255 (rounded)
inline unsigned div255(unsigned x) {
    return (x + 128) * 257 >> 16;
}
```
