**Section 1: Rendering Pipeline**
- Introduction explaining draw call flow
- Mermaid flowchart LR diagram:
  ```
  Draw Call -> Transform (CTM) -> Clip (Viewport) -> Rasterize (Edges->Pixels) -> Shade (Color) -> Blend (Composite) -> Framebuffer
  ```
- Style nodes with forest green (#2E7D32, #1B5E20)
- Add `role="img"` and `aria-label` for accessibility
- Include `<details>` element with text description of pipeline

**Section 2: Canvas Abstraction**
- Explain GCanvas as abstract interface
- Mermaid class diagram showing:
  - GCanvas (interface) with key methods (save, restore, concat, clear, drawRect, drawConvexPolygon, drawPath, drawMesh, drawQuad)
  - MyCanvas (implementation)
  - Factory function GCreateCanvas
- Brief code snippet showing canvas creation pattern

**Section 3: Shader System**
- Explain shader hierarchy for color generation
- Mermaid flowchart showing shader types:
  - GShader (base interface)
  - BitmapShader (texture mapping)
  - LinearGradientShader, RadialGradientShader, AngleGradientShader (gradients)
  - ProxyShader, ComposeShader (composition)
- Explain setContext() and shadeSpan() contract

**Section 4: Transformation Stack**
- Explain CTM (Current Transformation Matrix) concept
- Mermaid sequence diagram showing save/concat/restore flow:
  ```
  User->>Canvas: save()
  Canvas->>Stack: push CTM
  User->>Canvas: concat(rotate)
  Canvas->>CTM: multiply matrix
  User->>Canvas: drawRect()
  Canvas->>Rasterizer: draw with rotated CTM
  User->>Canvas: restore()
  Canvas->>Stack: pop CTM
  ```
- Brief code example showing transformation pattern

**Section 5: Blend Pipeline**
- Explain Porter-Duff compositing model
- Table of blend modes with formula descriptions
- Mermaid diagram showing src/dst pixel combination
- Link to core-rendering.html for detailed blend mode explanations

**Footer:**
