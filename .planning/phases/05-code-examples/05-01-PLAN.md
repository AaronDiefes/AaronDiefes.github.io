<task type="auto">
  <name>Task 2: Create accessible tab JavaScript</name>
  <files>docs/assets/js/tabs.js</files>
  <action>
Create docs/assets/js/tabs.js implementing the accessible tab pattern from RESEARCH.md:

**Core functionality:**
- Find all [role="tablist"] containers on page
- For each tablist, bind click handlers to [role="tab"] buttons
- Implement selectTab(tab) function:
  - Set aria-selected="true" on clicked tab, "false" on siblings
  - Set tabindex="0" on clicked tab, "-1" on siblings (roving tabindex)
  - Show corresponding tabpanel (aria-controls points to panel id)
  - Hide sibling tabpanels with hidden attribute

**Keyboard navigation:**
- ArrowRight: Focus and select next tab (wrap to first)
- ArrowLeft: Focus and select previous tab (wrap to last)
- Home: Focus and select first tab
- End: Focus and select last tab
- Prevent default on arrow keys to avoid scroll

**Initialization:**
- Run on DOMContentLoaded
- Support multiple independent tablists on same page
- Handle case where no tabs exist (no errors)

Do NOT use jQuery or any library. Pure vanilla JS with modern syntax (const, arrow functions, querySelectorAll).
  </action>
  <verify>
Create a minimal test HTML with tabs structure, include tabs.js, verify:
1. Click switches tabs
2. Arrow keys navigate
3. aria-selected updates correctly
  </verify>
  <done>
Tab system works with keyboard and mouse, meets WCAG 2.1 accessibility requirements for tabbed interfaces.
  </done>
</task>
